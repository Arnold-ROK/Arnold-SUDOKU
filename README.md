# Arnold-SUDOKU
Sudoku created by Arnold — **RYK SUDOKU**

- Installable web app that works offline
- 7 languages: 한국어, English, 日本語, 简体中文, Español, Français, Deutsch
- Difficulty levels, notes, hints, undo, erase and per-device time records
- Built-in instructions in every language, and colorful fireworks when you solve a puzzle
